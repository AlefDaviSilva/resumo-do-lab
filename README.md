# resumo-do-lab
Resumo do Lab: Portal do Microsoft Azure

Este repositório contém o resumo das lições aprendidas durante o desenvolvimento do lab na DIO
No laboratório, explorei o Portal do Microsoft Azure, que é a interface web usada para gerenciar todos os serviços e recursos da plataforma Azure. Aprendi como utilizar diversas ferramentas para configurar, monitorar e organizar recursos, além de personalizar a experiência de acordo com as minhas necessidades.

Ao acessar o portal (portal.azure.com), fui apresentado à dashboard (tela inicial), que oferece uma visão geral dos recursos e serviços disponíveis. O painel é altamente personalizável, permitindo adicionar atalhos (tiles) para os recursos mais utilizados, facilitando o acesso rápido aos serviços essenciais.

Uma das primeiras tarefas foi aprender a criar novos recursos no Azure, como Máquinas Virtuais (VMs), bancos de dados SQL, contas de armazenamento e redes virtuais (VNets). Para criar um novo recurso, basta clicar em "Criar um recurso" e escolher o serviço desejado, ajustando a configuração conforme a necessidade do projeto.

Aprendi também a organizar os recursos usando Grupos de Recursos, que permitem agrupar serviços relacionados de maneira lógica. Isso facilita o gerenciamento e o acompanhamento, especialmente em projetos maiores, onde múltiplos recursos, como máquinas virtuais, bancos de dados e redes, podem ser organizados em um único grupo.

O portal também oferece ferramentas robustas para monitorar e diagnosticar o desempenho dos recursos. Utilizando o Azure Monitor, consegui verificar a utilização de CPU, memória e armazenamento das minhas VMs e outros serviços, além de explorar os Logs de Atividade, que registram as ações realizadas no portal. Esses logs são essenciais para auditoria e resolução de problemas, garantindo que todas as modificações nos recursos possam ser rastreadas e analisadas.

Outro ponto importante foi a configuração de segurança e controle de acesso. Através do Azure Active Directory (Azure AD), aprendi a gerenciar autenticação e controle de identidade para diferentes usuários. O RBAC (Role-Based Access Control) também foi fundamental para definir permissões específicas, garantindo que cada usuário ou grupo tenha acesso apenas aos recursos que são necessários para suas funções.

No Azure Marketplace, explorei uma ampla gama de soluções e aplicativos de parceiros que podem ser implementados diretamente no Azure. Esse marketplace oferece uma maneira rápida de expandir os recursos do meu ambiente, com aplicativos como máquinas virtuais e bancos de dados prontos para uso, facilitando a implementação de novos serviços.

Além disso, o portal se integra facilmente com ferramentas de automação, como o Azure CLI e Azure PowerShell, permitindo a execução de comandos e scripts diretamente da linha de comando para automatizar tarefas e gerenciar recursos em larga escala.

Por fim, o portal oferece acesso fácil ao suporte técnico e à documentação oficial, para que eu possa obter ajuda sempre que necessário. Caso surjam problemas ou dúvidas, posso abrir tickets de suporte ou consultar a documentação detalhada para encontrar soluções rápidas e precisas.

Em resumo, o Portal do Microsoft Azure é uma plataforma centralizada e poderosa para gerenciar recursos de nuvem. Durante o laboratório, aprendi a usar o portal para criar, organizar, monitorar e proteger meus recursos de forma eficiente. A personalização do painel, a criação de grupos de recursos e o acesso a ferramentas como o Azure Monitor e o Marketplace foram essenciais para me ajudar a administrar e otimizar os serviços no Azure.
